02 · Build a hierarchy, choose linkage, read the tree

Agglomerative & Divisive clustering

Hierarchical clustering builds nested groups that can be shown as a tree called a dendrogram. You can explore broad groups or smaller subgroups by choosing where to cut the tree.

Agglomerative clustering works bottom-up: each observation starts alone, then the closest groups merge step by step. The linkage method defines how closeness between groups is measured. Divisive clustering works top-down: all observations start together, then groups are split into smaller ones. For example, six observations can be joined from six groups into one, or separated from one group into smaller groups. The two approaches need not produce the same tree.

Height has meaning

Branches join at the linkage height of a merge. Single, complete and average use cross-group distances. Ward uses a variance-based criterion; its plotted height follows SciPy’s convention, √(2 × increase in within-group SSE).

A cut gives a partition

A horizontal cut groups the leaves connected below it. Move through a large gap between merges and ask whether that partition is useful. At an exact merge height, this activity includes that merge.

Leaf spacing is not distance

Leaves can be reordered by rotating branches without changing the hierarchy. Read the joining heights, not horizontal gaps. These trees are computed from Euclidean distances; Ward requires Euclidean geometry.

03 · DBSCAN · Density-Based Spatial Clustering of Applications with Noise

DBSCAN

DBSCAN looks for dense regions connected through nearby observations. Unlike K-means, it does not start with centres or a requested cluster count. You choose a neighbourhood radius ε and a minimum count MinPts; groups emerge as the algorithm explores those neighbourhoods.

How to read the expansion

  1. 1 · Check a neighbourhoodChoose an unvisited point and count observations within ε, including the point itself.
  2. 2 · Find enough local supportAt least MinPts observations make it core. A core point not reached by an existing group starts a new one.
  3. 3 · Follow the neighboursCore points add neighbours to the search. Non-core neighbours can join as border points, but do not expand it.
  4. 4 · Finish and repeatWhen the search is exhausted, inspect remaining unvisited points. Final noise lies outside every core neighbourhood.

For example, MinPts = 5: the point plus four neighbours is enough to be core. The point plus only two neighbours is not core; it may still be border if a core neighbourhood reaches it.

The highlighted step follows the animation below. A group can stretch along a chain of core neighbourhoods: its far ends do not need to be within ε of each other.

During expansion, a non-core point may be marked noise provisionally, then become a border point when a core group reaches it. Only core points expand the search.

Core

At least MinPts observations lie within ε, counting the observation itself. Its neighbourhood can expand the group.

Border

Fewer than MinPts neighbours, but within ε of a core point. It joins a group without expanding it.

Noise

Not core and not within ε of any core point. Noise means unassigned under these settings; it does not prove that an observation is an error.

Core connectivity defines the groups. A border point touching two groups may receive either label depending on traversal order. Colours and group numbers are arbitrary.

04 · Choose parameters with evidence

One radius changes the story.

This graph helps you choose DBSCAN’s neighbourhood radius, ε. Each dot shows how far an observation must reach to count MinPts observations, including itself; the distances are sorted from smallest to largest. With MinPts = 5, this reaches the fourth other neighbour. A bend suggests a radius to try—click a dot to test its effect.

Interactive graphClick a dot to try its distance as ε ↓The dashed line and clustering results update with your choice. You can also Tab to a dot and press Enter.

Look, adjust, explain.

  1. Inspect any bend as a candidate, not a guaranteed optimum.
  2. Small ε may leave many observations unassigned; large ε may connect distinct groups.
  3. Increase MinPts to demand more local support. Check which regions become noise.
  4. Try different densities: one global ε may fail to recover both groups.

Adjust ε and MinPts in Topic 3 to see the effects on exactly the same observations. Clicking the graph rounds the distance to the control’s 0.5-unit step, within 1–30.

Feature scaling changes distances and the meaning of ε. In the notebook, choose parameters on the prepared data, not by copying a radius from another scale.

K-means

Nearest-centroid assignments; every point joins a group. Favours compact, roughly spherical groups under Euclidean distance.

Agglomerative

Builds nested groups according to linkage. A requested cluster count gives a partition; all observations are assigned.

DBSCAN

Finds connected dense regions, including curved shapes. Can mark noise; sensitive to scaling and different densities.
